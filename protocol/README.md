# Review protocol artifacts

This directory provides public-safe artifacts needed to verify literature identification and screening accounting without redistributing database exports, article titles, abstracts, or full text.

- `search_strategy.md`: database-specific searches run on 28 April 2026
- `prisma_flow.csv`: study-flow counts underlying main-text Figure 2
- `fulltext_exclusion_reasons.csv`: aggregate full-text exclusions
- `screening_benchmark_metrics.csv`: aggregate metrics reported in main-text Table 1

Detailed eligibility and governance rules are described in the manuscript Methods and Supplementary Methods.
