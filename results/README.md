# Results

Generated by `python scripts/reproduce_results.py` from `data/` and `audit/`. All removal summaries use full-scale systems (Tier 1) unless the file name says otherwise. Values are study-level: each study contributes the median of its rows to a cell. Bootstrap intervals come from one deterministic random stream; the intervals reported in the manuscript are those in `removal_main_route_by_gene_family.csv` and `removal_by_route.csv`. The reported-detection summary (Table S22) is in `data/reported_detection_by_family_and_matrix.csv`.
