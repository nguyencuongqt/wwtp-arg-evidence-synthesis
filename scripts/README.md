# Scripts

- `15_rerun_frozen_dl_i2.py`: regenerates route-, family-, and treatment-level removal summaries and heterogeneity diagnostics.
- `15_regenerate_axis2_v2_outputs_20260730.py`: regenerates the corrected family-by-matrix abundance summary.
- `verify_checksums.py`: verifies files against `metadata/SHA256SUMS.tsv`.
- `build_checksums.py`: regenerates the release checksum manifest after an intentional update.
- `validate_public_release.py`: checks for forbidden file types, local paths, caches, and disallowed text-bearing columns.

Publication figures are already supplied with the journal submission and are not duplicated in this repository.
