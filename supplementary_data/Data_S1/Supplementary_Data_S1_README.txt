Supplementary Data S1 — Critical appraisal and mapping to the final analysis

This bundle contains the author-approved, outcome-specific critical appraisal of 64 units. X.C.N. and T.U. independently reviewed the source-PDF evidence, reconciled disagreements, and jointly accepted the final judgments on 13 September 2026. The domain file contains 320 domain-level decisions (five domains per unit); the unit summary contains the five final domain judgments and overall judgment for each appraisal unit.

The mapping file links all 64 appraised units to the final v4 datasets. Forty-four units contribute 120 outcomes to the primary full-scale log10-reduction dataset. The final primary dataset has 126 outcomes: six reverse-osmosis outcomes added from the source for R0328 after appraisal are not mapped to an appraisal unit. Among the 44 contributing units, 1 was Low concern, 38 had Some concerns, and 5 were Critical concern / insufficient reporting.

Files
- Supplementary_Data_S1_final_domain_decisions.csv: reviewer judgments, final reconciliation, DOI, and source locator for each domain.
- Supplementary_Data_S1_final_unit_summary.csv: one row per appraisal unit.
- Supplementary_Data_S1_appraisal_to_v4_mapping.csv: unit-to-final-dataset mapping and outcome counts.

The same source records are archived in the reproducibility repository under audit/critical_appraisal/.
