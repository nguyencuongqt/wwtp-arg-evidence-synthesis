Supplementary Data S2 — Final v4 risk-of-bias sensitivity analysis

This bundle is regenerated from the October 2026 v1.3.0 reproducibility package after the R0328 author-confirmed endpoint correction. It evaluates the primary full-scale dataset (126 outcomes / 30 studies) and excludes the 16 outcomes in that dataset linked to Critical concern / insufficient reporting appraisal units. The restricted dataset contains 110 outcomes / 25 studies. The main influent-to-final-effluent route contains 66 outcomes / 20 studies before restriction and 57 / 18 after restriction.

The full appraisal source contains 22 critical outcomes across all scales; six do not belong to the primary full-scale dataset and are therefore not counted as primary sensitivity exclusions. Do not use the superseded August 2026 Data S2 counts (179 to 157 rows).

The report explains the principal results and interpretation limits. CSV files provide the excluded outcomes and full/restricted summaries. The JSON file records validation counts. Pooled estimates are diagnostics because sampling variances are imputed.
