Data S3. Detailed supplementary tables in machine-readable format

This companion dataset preserves full tabular detail moved from the Supplementary Information: screening benchmark labels and metrics, high-risk false-exclusion record IDs, model and prompt provenance, five-study-threshold sensitivity, claim-confidence boundaries, quantitative-core study characteristics, gene-family by route summaries, percent-removal evidence, treatment-category by gene-family cells, and reported-detection counts.

Files are CSV with UTF-8 encoding. Values and labels were copied from the final SI tables; no data were recalculated in this packaging step. Condensed SI tables retain key narrative summaries while these files support detailed lookup and reuse.

File map: screening_gold_set_label_distribution.csv (former Table S2); screening_benchmark_metrics.csv (former S3); screening_high_risk_false_exclusions.csv (former S4); model_provenance_prompt_rule_archive.csv (former S6); five_study_threshold_sensitivity.csv (former S14); evidence_confidence_boundaries.csv (former S16); quantitative_core_study_characteristics.csv (former S18); gene_family_by_route_log10_reduction.csv (former S19); percent_removal_summary.csv (former S20); treatment_category_by_gene_family.csv (former S21); reported_detection_landscape.csv (former S22).

Data S3 supplements Data S1 and Data S2, which retain their critical-appraisal and sensitivity-analysis roles.
