# WRX companion data bundles

Data S1 and Data S2 reproduce the companion files prepared for the Water Research X submission. Data S1 is the final author-approved appraisal and mapping to v4; Data S2 is the final full-scale risk-of-bias sensitivity analysis after the R0328 correction. Source records and reproducibility code remain in `audit/critical_appraisal/`, `data/`, and `results/`. The bundle hashes are listed in `metadata/SHA256SUMS.tsv`.
