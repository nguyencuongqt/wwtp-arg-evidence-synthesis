# Water Research X companion data

The ready-to-submit companion data are supplied in one archive, `Supplementary_Data_S1-S3.zip`. It contains three folders whose identifiers match the citations in the manuscript:

- `Data_S1/`: critical-appraisal domain decisions, unit summaries, and mapping to the final v4 dataset.
- `Data_S2/`: critical-concern outcomes and full-versus-restricted sensitivity results.
- `Data_S3/`: supporting screening, model-provenance, study-characteristic, route, treatment, abundance, detection, and evidence-boundary tables.

The archive preserves the original CSV, JSON, TXT, and Markdown files. The extracted folders are also available here for direct inspection. Source records and reproducibility code remain in `audit/critical_appraisal/`, `data/`, and `results/`. File checksums are listed in `metadata/SHA256SUMS.tsv`. The consolidated companion archive was added after the v1.3.0 Zenodo deposit; the archived v1.3.0 snapshot is unchanged.
